Cài đặt

cd project-của-bạn
git clone https://github.com/kitajima2910/pxhopencode.git .opencode
.opencode\start.bat

start.bat: remove nested .git, init memory, merge .gitignore, launch opencode.

Sử dụng

Trong opencode, gõ prompt tiếng Việt:

"Xây dựng web blog với React"

Hoặc lệnh /:

/detect           # Auto-detect project framework
/status           # Memory + pipeline state
/diff             # Xem thay đổi
/rollback src/    # Rollback file
/feedback         # Gửi feedback
/secret set OPENAI_KEY=sk-...  # Lưu secret
