# Flow Factory 授權管理后台

此工具供项目管理员在 macOS 本机管理授权使用。双击 `scripts/create-license.command` 后，会启动只监听 `127.0.0.1:18766` 的本地服务，并自动打开浏览器管理页面。

## 可以做什么

- 查看最多 500 笔授权记录、状态、类型、首次启用日、到期日、设备上限和已绑定设备数。
- 一次建立 1–100 个月费或终身授权码。
- 修改授权类型、月费到期日、设备上限及启用状态。
- 清除指定授权的设备绑定，让客户重新激活。
- 在「授權商店」分頁審核用戶上傳的工廠，可通過上架、拒絕或下架已公開項目。
- 用戶自行下架後，項目會保留在後台記錄中，但不再出現在公開商店。
- 新建的完整授权码会显示一次并复制到剪贴板。
- 新建月费授权码不会立即倒数；客户第一次成功启用时，才按创建时设置的有效月数计算到期日。后续增加允许的设备不会重新计时。
- 已存在的旧月费授权继续沿用原到期日，不会因本次升级自动延长或缩短。

## 使用方法

1. 双击 `scripts/create-license.command`。
2. 第一次使用时输入 Cloudflare Worker 的 `ADMIN_TOKEN`。工具会将其保存到当前用户的 macOS 钥匙串，以后无需重复输入。
3. 在浏览器打开的管理页面中查看或调整授权。
4. 关闭启动脚本的终端窗口，即可停止本地管理服务。

如果后台曾经残留运行，再次双击启动器会自动识别并关闭旧实例，然后打开带有全新安全会话的管理页面。列表读取期间会显示进度；连接失败时会在表格内显示原因与重试提示。

## 安全设计

- 管理 Token 只由本地 Python 服务从 macOS 钥匙串读取，不会传给浏览器，也不会写入 GitHub。
- 本地后台只监听 `127.0.0.1`，并为每次启动生成随机会话凭证。
- Cloudflare D1 只保存授权码 SHA-256 哈希。旧授权可以管理，但无法恢复完整明文。
- 完整授权码只在创建时返回一次，请通过安全渠道交给客户。

## 文件组成

- `scripts/create-license.command`：macOS 双击启动器。
- `scripts/license_admin.py`：本地安全代理与后台服务。
- `scripts/license_admin.html`：授权管理页面。
- `scripts/create_license.py`：可选的命令行批量生成工具。
- `cloudflare/license-worker/`：Worker API 与 D1 migrations。

## 常见问题

如果端口 `18766` 已被占用，请先关闭之前打开的授权管理终端窗口。如果钥匙串中的 `ADMIN_TOKEN` 已失效，应在 Cloudflare Worker 中轮换 Secret，并更新 macOS 钥匙串中的 `FlowFactory License Admin Token`。
