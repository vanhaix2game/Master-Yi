# 專案版本與發布規則

每次完成程式碼修改並準備推送 GitHub 時，必須依序執行：

1. 根據語意化版本決定新版本號：修正升 Patch、新功能升 Minor、不相容改版升 Major。
2. 執行 `python3 scripts/release.py <版本號> <中文摘要> [中文細節...]`，同步更新 `VERSION` 與 `CHANGELOG.md`。
3. 執行適合本次修改的測試與 `git diff --check`。
4. Git 提交訊息必須使用中文，格式為 `v<版本號>：<中文摘要>`。
5. 建立附註標籤 `v<版本號>`，標籤說明必須使用中文。
6. 推送程式碼與標籤：`git push origin <分支>` 及 `git push origin v<版本號>`。
7. 回覆使用者時，以繁體中文列出版本號、提交、標籤、修改內容與測試結果。

不得跳過版本號或重複使用已發布的版本號。若使用者只要求本機修改而未要求推送，先保留未提交狀態，等使用者確認推送時再執行發布流程。
